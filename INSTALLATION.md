# 🚀 Installation Rapide - Vinted Auto Republisher

## ✅ Étapes d'installation (5 minutes)

### 1. Ouvrir Chrome Extensions
1. Dans Chrome, tapez dans la barre d'adresse : `chrome://extensions/`
2. Activez le **"Mode développeur"** (bouton en haut à droite)

### 2. Installer l'extension
1. Cliquez sur **"Charger l'extension non empaquetée"**
2. Sélectionnez le dossier `vinted-republisher` (ce dossier)
3. ✅ L'extension apparaît dans votre liste !

### 3. Tester l'installation
1. Allez sur [vinted.fr](https://www.vinted.fr)
2. Connectez-vous à votre compte
3. Cliquez sur l'icône de l'extension dans la barre d'outils Chrome
4. Vous devriez voir l'interface du plugin

## 🎯 Première utilisation

### Accéder à vos annonces
- Allez sur votre profil Vinted
- Ou cliquez sur "Mes articles" dans le menu

### Utiliser le plugin
1. **Cliquez sur l'icône** de l'extension dans Chrome
2. **Scanner** : Cliquez sur "Scanner les annonces"
3. **Sélectionner** : Cochez les annonces à republier
4. **Republier** : Cliquez sur "Republier les sélectionnées"

## ⚙️ Paramètres recommandés pour commencer

```
Recadrage : 5%
Watermark : Activé (texte vide)
Rotation : 0.5°
Qualité : 5% de réduction
Délai : 1 minute entre annonces
Maximum : 10 annonces par session
```

## ⚠️ Important

- **Testez d'abord** avec 1-2 annonces
- **Ne pas abuser** : 1-2 sessions par jour maximum
- **Surveillez vos annonces** après republication
- **Variez les paramètres** régulièrement

## 🆘 En cas de problème

### L'extension ne se charge pas
- Vérifiez que tous les fichiers sont présents
- Actualisez la page `chrome://extensions/`
- Redémarrez Chrome

### Pas d'annonces détectées  
- Assurez-vous d'être sur une page avec vos articles
- Actualisez la page Vinted
- Ouvrez la console (F12) pour voir les erreurs

### Republication qui échoue
- Vérifiez votre connexion internet
- Réduisez le nombre d'annonces
- Augmentez le délai entre republications
